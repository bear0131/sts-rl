# 无文字因果房间试玩

本目录是独立的静态网页原型。进入仓库根目录后运行：

```powershell
python -m http.server 8878 --bind 127.0.0.1 --directory apps/causal_rooms
```

然后打开 <http://127.0.0.1:8878/>。不需要训练环境、模型或构建步骤。

页面没有可见说明文字，数值改用阿拉伯数字：蓝色为玩家当前/最大生命，暖橙色为怪物生命，金色为当前攻击力，红色负数为本关累计掉血与各回合实际掉血。亮度和闪烁速度仍辅助表达攻击强度；右上只记录已经发生的伤害，未来意图不显示。点击怪物可切换目标；底部依次为攻击、仅在蓄势关出现的蓄势、结束回合。每回合至多攻击或蓄势一次，也可直接结束回合。

路线包含原始互馈增幅三场，以及蓄势、连坐、回盾三组各六场示例和一场反例。每关独立从 20 生命开始；失败可在本关重试。初始只开放第一关，通关后解锁下一关；左上数字按钮可选择已解锁关卡，解锁和最好通关记录保存于当前浏览器。左上回环按钮重试当前关卡。通关时金色星形表示本关达到最低损血且未重试，银灰环表示存活通关但并非完美；死亡时显示红色碎形。最终结算也区分全程完美与容错通关。完美不是继续游戏的条件。

规则与核算见 `docs/2026-09-28/reciprocal-growth-encounter.md` 和 `docs/2026-09-28/misleading-encounter-curriculum.md`。页面对玩家理解规则的效果尚未做真人试玩验证。
