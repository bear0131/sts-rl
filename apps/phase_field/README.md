# 折相域试玩原型

这是一个独立于 STS 环境、策略和训练入口的静态浏览器原型。宏观保留地图、房间、回合和 Boss；局内只有色结、连线、相位、旋向、延迟回声和全局演化。画面不显示血量、格挡、能量、伤害、Buff 或文字提示。

## 启动

在仓库根目录运行一个静态服务器：

```powershell
python -m http.server 8765 --directory apps/phase_field
```

然后打开 <http://127.0.0.1:8765/>。可用 `?seed=20260928` 固定匿名图标排列和颜色起点。

## 操作

- 点击画布中的色结选择局部对象，再点击底部五个同级抽象操作之一。
- 四个操作只改变局部场，并在本次全局演化前锁定一次。
- 第五个操作外观同级，但会推进全局相位、传播、位置轮换和延迟回声；它不是一个带文字标签的“结束回合”按钮。
- 每个房间的目标相位在进入时固定；目标窗与中央场共享节点身份和连线，节点外侧六个方向的彩色刻度表示循环相位，亮刻度是当前方向。
- 全局演化会依次回放起始、漂移、传播、回声和位置轮换。回放期间暂时锁定操作，结束后再显示房间结果；传播连线和触发回声的节点会在对应阶段亮起。
- 普通房间成功后点击中央几何符号进入下一房间；失败后点击同一符号重开当前房间。
- 右上角环形符号随时重开当前房间。

第一、第二房间分别在一次全局演化后提供容易成功的轨道；第三房间让少量局部干预有用；Boss 初态会改写传播方向，允许测试“过度操作”与提前触发全局演化的差异。
