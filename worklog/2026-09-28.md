## Default development to main

用户原始意图：“我们为什么不在 main 分支上工作？除非实在高风险重构，否则不要再生产更多没用的分支了。写进 AGENTS.md 里。”范围为明确默认分支约定并在 main 提交，验收为 AGENTS.md 规定普通工作直接 main、仅高风险重构例外，文档提交同步 origin/main。

此前沿用 `codex/combat-rule-baseline-20260918` 的原因是历史训练/策略工作持续积累在该分支，没有及时收回 main；本次规则修改没有隔离需要。fetch 后起点为该分支 `9409317`，`origin/main` 为 `85c1283`，`git rev-list --left-right --count origin/main...HEAD` 为 2/214。工作区干净，直接切到已有 main；保留历史分支及其中尚未整合的功能，不把214个提交的集成混入本次文档修改。

AGENTS.md 增加：默认 main 开发/提交/push；仅确需隔离的高风险重构可新建分支，说明风险和合回验收；普通任务、日期、agent 和备份均不构成开分支理由，恢复点优先已有 commit/tag；历史分支先查差异并保护未合并工作。未新增分支，未修改运行时或远端训练。

验证：审查 diff/status，`git diff --check`；纯文档不跑算法测试。本节随当前提交推送 origin/main，随后核对本地/远端 tip 与干净工作区。历史功能回归 main 的集成尚未执行，需要单独审查处理；本次规范修改已完成。
