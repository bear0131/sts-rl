### 核实与判断

- `rl/algorithms/ppo.py` 的普通 PPO value loss 是 return 与预测 value 的 MSE；分层模式对有效样本计算同一平方误差，并按 combat/overworld 两类等权聚合。`vf_coef` 只决定它在总 loss 中的权重，不改变所记录 MSE 的数值。
- `rl/algorithms/hierarchical_returns.py` 中上层 return 以战略转移为时间尺度：上层动作后的战斗期间奖励被汇总，并从下一个上层状态 bootstrap；discount 不是按每个战斗原子动作重复施加。所以上层策略到达更深楼层、出现更多终局/路线分化时，target 分布可同时移动和增宽。
- 截图中 loss 从接近 0 平滑升至约 0.12，并在约第 120 个 legacy step 后围绕该值波动。该形态本身不像无界数值发散，更符合 target 分布变宽或变难后误差进入稳定平台；早期接近 0 也可能只是短局、低回报和窄 target 容易由接近零的 value 预测拟合，不能视为早期 critic 更好。
- 仅凭 value loss 不能判断 policy 变好或变坏。若该值确为未乘 `vf_coef` 的 MSE，0.12 对应约 0.346 的 RMSE，但其实际严重程度完全依赖 return 的归一化和方差。
- 首要联看相同 upper 样本上的 return/target mean 与 std、explained variance、value bias/MAE，以及完整局长度、楼层/胜率。若 target std 上升且 explained variance稳定或改善，loss 上升通常可接受；若 target分布稳定而 loss 上升、explained variance降到 0 或负值、bias扩大，并伴随 KL/梯度异常或表现下降，才更像 critic 跟不上或训练不稳。
