# 历史工作记录

原 doc/ 的日期记录与 docs/ 的阶段性实验报告按来源保留原文；input/ 是用户提供的当前实验说明快照（2026-09-13），不代表实时状态或运行授权。
不为历史文件重新编造日期，也不把旧结论升级成规范。此后进度只追加 worklog/YYYY-MM-DD.md。
旧文中的路径/相对链接可能仍引用原位置：用 docs/path-migration.json 或 `python -m tools.validation.locate_legacy OLD_PATH` 找当前文件；原字节 SHA256 在该映射中可核对。原始 JSON/CSV/图片/log 位于 artifacts/archive。
