状态：设计稿，未实现、未启动实验、未切换 COMBAT45。记录日期：2026-11-10（Asia/Shanghai）。任务身份与进度唯一入口为 TODO.md 的 DECK-LATENT-COMBAT；本稿细化此前架构，不另建运行入口。

## 用户意图与本阶段边界

用户要求训练阶段以较低搜索量学习卡组组合、关键能力开启时机和出牌顺序，正式评测再启用大搜索；最终内层保留当前战后锚点，锚点评价需可被搜索快速重复调用。允许先用当前纯强化学习方式预热；奖励和其他训练设置尽量沿用现役配置，明确要求“暂时不动当前的训练”。

本阶段验收是可实现、可审查的模型和训练协议：定义输入、缓存、三个价值接口、搜索工作量、监督标签、采样分布、预热切换及比较口径。不承诺未测的速度、胜率或超参数最优性。实现、部署和性能测量属于后续阶段。

## 模型：同一 checkpoint，按阶段激活

| 模块 | 首版尺寸 | 输入与输出 | 推理触发 |
|---|---|---|---|
| 构筑编码器 E | 8层×512，8头，FFN4倍 | 完整永久卡组、升级/永久实例信息、静态遗物身份；输出全卡组z_D∈R512及外层可用的实体表示 | 编码输入或权重版本改变 |
| 外层 actor/critic | 2层×512 | z_D、完整构筑表示、当前外层观察和合法候选；π_U、V_U | 外层真实决策 |
| 战斗公共网络 | 两层128宽 | 缓存z_D投影/调制系数＋动态玩家/敌人/牌堆/药水摘要 | 战斗真实或模拟状态 |
| 战斗动作网络 | 64宽实体表示与源/目标耦合 | 精确手牌/药水/选择候选、公共上下文和目标；π_C | 每次非强制战斗决策 |
| 战斗 critic V_C | 复用战斗公共表示，小型标量头 | 当前战况＋z_D | 真实PPO行或搜索深度截断 |
| 战后锚点 critic V_A | 两层256宽MLP | z_D＋公开战后资源/结果/房间信息 | 每条完整模拟链的出口、真实锚点行 |

这些尺寸是首个实验候选，不是已验证最优配置。V_A不运行大Transformer，也不需要重算整副卡牌。它与V_U/V_C共享构筑表示，但有独立的轻型输出模块，避免把“正在战斗”和“战斗已结束”混为同一种输入。

普通内层无全实体自注意力。先汇总上下文，再广播到手牌/敌人，按源实体和目标双线性/非线性交互评分。H个手牌＋M个有意义敌人＋1个公共向量；H=5、M=1–3时为7–9个上下文向量，另外计入药水、END与选择候选打分。不是声称所有输入只有7–9项，也不是无上下文线性查表。

永久构筑与当前战斗库存分开：抽牌、弃牌、消耗、手牌各维护 learned-sum 摘要和数量；药水按槽位摘要。普通移动仅更新加减，生成/变形/费用/升级事件更新受影响项。保留已知牌序/顶牌，隐藏未来和符文圆顶意图不能泄漏。力量、敌方易伤等全局变化在实时支路计算，不能错误缓存进每张牌的静态特征。

汇聚是学习压缩，非数学无损。选择界面仍读取每个精确候选，保留UID、物理槽位、pending来源、autoregressive-v2的逐项选择/STOP；半死/休眠/会复活敌人不能丢失。消耗堆、临时生成牌、药水替换和各类计数器都必须覆盖。

E、z_D投影及卡牌特征按模型版本/构筑内容缓存；世界线共享只读部分，动态摘要分支隔离。真实或假想分支内出现永久构筑变化时需重新编码对应内容，不能复用陈旧z_D。实现应由原生事件维护小摘要，避免先在Python重建长观测再压缩。优先导出FP32小网络和缓存向量供CPU原生批量推理，大编码器与训练反向使用GPU；CPU/GPU部署选择仍需同工作量实测，当前未实现导出路径。

## 锚点与目标：保持当前回报含义

锚点仍是当前实现中胜利/逃跑已经确定、尚未调用结算来生成/展示奖励的位置。搜索在这里停止，不偷看卡牌/药水/金币奖励。x_A取该分支真实的公开状态：HP/maxHP、药水、金币、永久构筑变化、可持续遗物计数、幕/房间/敌人类别和胜利/逃跑结果等；不能拿尚未同步的旧GameContext HP覆盖BattleContext新HP。可影响后续游戏的字段逐项定义，不能凭“战斗结束”省略。

V_A(z_D,x_A)的教师来自真实游戏未来的整局lambda=1回报。自然终局使用真实结果；rollout尾部仍按现役规则bootstrap，不能把768行的尾部当作游戏结束。搜索叶子对同一个V_A的多次调用不会自动产生新的V_A监督样本。

进入锚点阶段后，对真实战斗行t：

`G_C(t) = sum(real rewards from t until anchor) + stop_gradient(V_A_old(anchor))`

战斗优势为G_C−V_C_old。锚点行和之前/之后的外层行继续原整局lambda=1递推；不能顺便切断更早的选牌/构筑信用。死亡按真实终局奖励、零未来价值；逃跑使用自己的真实出口状态，不能当击杀。

搜索分支回报同一口径：

`Y(a,world) = sum(simulated original rewards) + V_A_frozen(exit)`

未到出口而遇到搜索深度上限，用V_C_frozen(current combat state)自举；死亡不用V_A。不额外添加“每点血多少分”“优先快杀”“开能力奖励”或胜利固定分。快杀、投入成长、保存药水的取舍由学到的整局价值产生；锚点估错时搜索也可能错，不能说搜索必然纠正critic偏差。

## 搜索：降低链数量，保留能力收益的时间范围

首版沿用共享世界线根枚举＋小策略推进。根部对每个合法首动作分别模拟，包含低先验能力、END、药水和合法子选择；不因policy暂时不喜欢就删去能力候选。不同根动作共享同一随机未来定义，随后由同一冻结π_C继续打；每条链只在出口调用V_A，在深度截断调用V_C，不在链内再次递归启动搜索。

根的决策粒度沿当前autoregressive-v2的真实原子动作/合法mask，pending前缀必须完整复制。不能直接把旧181联合动作的分数当作新前缀动作的概率；首版按canonical原子步进实现。链内按冻结π_C的合法分布采样（temperature=1），环境随机与策略随机使用明确的分支流。正式评测外层/无搜索policy使用确定性masked argmax，搜索根选择最大均值Q，精确同分按π_C再按稳定动作ID解；评测固定种子。训练指标仍是随机π行为，不与确定性评测混用。

| 用途 | 普通/精英/Boss名义模拟额度 | 实际动作 |
|---|---|---|
| 纯PPO预热 | 0/0/0 | π采样 |
| 稳态训练辅助搜索 | 64/64/256，约旧额度的1/4 | 仍由π采样，搜索提供旁路监督 |
| 便宜的诊断对照 | 0与64/64/256 | 明确分别为纯policy、搜索选动作 |
| 正式搜索评测 | 250/250/1000 | 搜索选择动作 |

不在每轮训练跑大型评测；更高正式预算是否值得，另按固定checkpoint、固定种子预先冻结比较。

预算定义为从指定根动作出发的一条链算一次simulation，不是一个世界、一个环境动作或一次模型前推。A为该根真实合法候选数；初版使用完整共享世界轮次：`K=max(1,floor(B_nominal/A))`、`B_actual=A*K`。A>B时为覆盖所有候选允许超过名义额度，单列次数和成本；其余根不强行花掉剩余不足一轮的额度。因此64不是64个世界，约1/4也不是严格每根恰好25%。强制单动作状态无需搜索，不产生虚假的改进标签。

减少预算先减少K，搜索深度仍保持参考200个原生决策上限，并分别记录完整出口/深度截断率。这样关键能力仍有机会在后续回合回本；不会把1000→256同时误改成只看1/4战斗长度。200不是有效步数保证，选择/强制推进按现役定义明确计数，未来实现须固定这一合同。

首动作枚举能比较出牌顺序的起点，之后每个真实局面再提供搜索监督；它不等于枚举整手牌的所有排列。暂不额外加入阶乘枚举/局部手写修正，避免一次更换多个算法。

## 训练采样与监督：PPO主任务＋搜索辅助任务

**第一版采用旁路搜索。** 真实环境仍从冻结π_old的合法分布采样动作，并记录对应logprob。搜索复制该状态，在独立RNG分支生成对比标签；不得改变真实环境、随机流、pending或实际动作。无论搜索推荐是否被采样，真实轨迹都保留。

因此当前PPO数据仍来自其声明的行为policy。不能将搜索argmax动作塞入当前PPO，再用网络logprob假称它由网络采样；要让搜索直接接管训练轨迹，应另设计行为分布/离策略修正，本版不做。这个选择也意味着训练胜率是纯policy能力，正式大搜索胜率另标口径，不能混为同一条曲线。

每个搜索根保留所有动作均值Q_a、配对世界回报、K、原始π_old、出口/截断计数、teacher模型版本。低样本不强塞固定top1质量。首版冻结如下软改进目标：

```
b = sum_a pi_old(a) * Q_a
eta = K / (K + 4)
tau = max(0.02, 0.25 * std_of_real_return_targets)
d_a = eta * clip((Q_a - b) / tau, -2, 2)
q(a) = softmax(log_pi_old(a) + d_a), over legal actions
L_search = KL(pi_current || stop_gradient(q))
L_total = L_PPO_actor + 0.5 * L_real_value - 0.02 * entropy + beta * L_search
```

std来自本轮真实回报标签、跨rank一次归约并冻结，不使用虚拟搜索样本。log_pi_old用稳定log-softmax，不先把极小概率转为0；无效动作严格mask。eta是启发式低样本收缩，不是统计置信概率；2、4、.02、.25与beta均为候选超参数，不能称已验证最优。所有Q相等时q=π_old，不会退化为让模型学习均匀动作；样本少时减少对偶然胜出的强化。无需旧式固定0.8第一候选标签。

搜索loss在本rank已搜索的非强制真实根上取均值，跨rank按真实样本数归约；PPO/value/entropy继续以当前真实行的统计口径计算，不把每条模拟链当一个PPO样本。无搜索根时辅助梯度为0且指标缺失计数明确。beta从0线性升到0.1，进入稳态后固定，搜索辅助不增加Adam次数。KL方向沿用当前regret实现的student||soft-improved-prior解释；这里新增收缩、尺度和真实RL联合目标，是统计方法实验，不是等价重构。

V_U/V_C/V_A仅用各自真实行目标训练；不拿搜索max Q当V_A真值，避免自举放大和乐观偏差。搜索只教actor动作相对优劣，它的梯度可通过actor更新共享E，但Q/teacher/旧目标保持停止梯度。若共享表示导致critic退化需报告并消融，不能用更多训练次数掩盖。

## 预热与接入流程

预热从一开始就使用最终新架构，纯PPO是算法模式，不是在旧256×4训完后把权重强行装入8×512。真实锚点观察行从新run开始存在，但第一阶段不用它截断战斗回报；V_A仍直接学习真实整局回报。这样切换时不修改观察/动作结构或重新初始化已学的战斗模块。

这需要新模型合同将“观察中有锚点”与“战斗标签在锚点截断”分开配置；当前SharedWholeRunPolicy构造器绑定二者，不能直接给旧入口加一个开关就声称已支持。旧模型检查和兼容范围保持，新模型的阶段转换单独验证。

| 阶段 | 目标与回报 | 搜索与更新 |
|---|---|---|
| A：整局PPO预热 | 全部真实行gamma=lambda=1，V_A在锚点行学习整局回报 | 无搜索、无辅助loss |
| B：锚点适应 | 普通战斗行改用当前锚点合同，外层/锚点仍整局lambda1 | 至少20轮，无搜索，不重置模型/Adam/环境 |
| C：搜索渐进接入 | 保持B的真实目标 | 20轮内搜索根比例25%→50%→100%，beta 0→0.1，单根始终64/64/256 |
| D：稳态训练 | 保持B的真实目标 | 每个非强制根低预算旁路搜索，一遍联合更新；正式评测另跑大预算 |

首个准备度检查点设在100轮后，每20轮一次，数字是候选排程。使用独立于训练的固定验证种子组、每次64自然游戏、每局20000动作/每次900秒硬限，没完成的游戏明确删失不强计胜负；不运行480长队列。准备度看冻结V_A对实际未来整局回报的误差，而非对自己bootstrap标签的拟合：连续三次验证的锚点EV>0.05、有限性/终局/奖励选择无异常且指标未明显退化，才进入B；不要求打牌完美或通关率达到旧搜索模型。三次结果用于训练选择，不冒称独立盲测。若验证样本不足/未来回报无方差，门槛未通过。

B至少20轮后按同一验证口径确认V_A预测仍有效再进入C；若不满足，继续纯PPO并调查，而非盲目用不成熟价值制造大量搜索标签。正式部署可持续训练，但开发/试跑必须另写有限轮数和墙钟上限；本稿不授权实际启动无限实验。

C的搜索抽样使用独立调度RNG，按阶段/房间类型分层，避免只标易战斗；不可改变真实游戏RNG。同轮权重冻结，teacher仅供该轮一次更新，不引入跨版本长期replay。接入变化在完整采样边界发生，并在checkpoint保存阶段/计数/随机流。

## 一轮数据与更新顺序

1. 固定本轮模型版本，构筑缓存和原生小网络导出与该版本一致。
2. 真实环境按π_old采样；对选中的非强制战斗根复制状态运行低预算共享链，并记录Q与teacher来源。
3. 真实轨迹按原768行结束窗口，在途游戏继续；搜索轨迹不得进入自然局或环境步计数。
4. 从采样旧价值计算并冻结真实lambda/锚点目标及PPO优势，仍对786432真实行统一归一化；计算固定辅助标签。
5. 保持全局有效batch49152、16次Adam、1遍、LR5e-5；辅助项并入同一更新。新结构重测物理分块，仅按等价梯度累积调整显存，不擅自扩大有效batch或更新次数。
6. 训练时对每个小批唯一构筑用当前E重新编码并保留计算图，外层/战斗/锚点损失共同反向。不能把采样时detached z_D当永久训练输入。每次权重改变后缓存失效。
7. 同步模型与优化器；记录/保存阶段、合同、样本与搜索计数及环境/RNG，下一轮刷新小网络及缓存版本。

保留当前奖励、遗物优先的顺序奖励界面、autoregressive-v2、公开信息约束、1024×768采集、FP32、lambda1、学习率/更新频率和优势归一化。新网络结构、三个价值分支和辅助搜索目标是明确的新实验，旧checkpoint不直接几何兼容；不能把本稿称为原训练的无损续训。

## 要验证什么

- 能力：新架构纯PPO与新架构PPO+低预算搜索分别训练，在相同真实样本数、相同墙钟两种口径比较；冻结同一checkpoint分别用0、1/4、完整搜索量评测，分开模型学习和在线计算贡献。开发用固定64局筛查，正式冻结128配对自然游戏及独立种子，不根据结果换种子；未完成结果单列。不以一次小样本显著性宣传稳定提升。
- 机制：按构筑/敌人/阶段记录开能力时机、花费/回本、战后HP与药水、Boss胜率，以及配对根的选牌/顺序改进和损害。首动作比较不是完整排列证明，能力出牌次数多不等于更聪明。训练loss/KL不是唯一验收指标。
- 锚点：分别记录V_A对实际整局回报的误差/EV，真实与搜索出口状态分布、HP/药水/永久改变的反事实敏感性；反事实单调性不能不顾代价和后续策略直接当真值。大型搜索有可能利用V_A误差，所以增预算并不保证胜率单调提高。
- 性能：真实环境动作、非强制根、simulation链、链内原子transition、π_C/V_C/V_A调用、强制跳过、构筑重算分别统计；提供采样/搜索/叶评价/编码IPC/更新/同步/保存墙钟及资源。不得把搜索虚拟样本当有效PPO batch变大。
- 正确性：实际锚点与模拟锚点同边界/资源/奖励；缓存与全量重算前向及梯度对照；永久改写、药水、牌堆、pending、Dome和分支隔离；旁路搜索前后真实RNG/状态/动作轨迹不变；2轮真实采样/聚合/保存恢复；如启用GPU graph，需生产长度的形状/淘汰/临时内存释放重放。

实现归属：policies负责条件模型/三价值接口，algorithms拥有联合目标并复用updates及训练传输，env/search负责原生无模型搜索与摘要，evaluation实现DecisionStrategy/PhaseStrategy。复用现有codec/outcome，不复制trainer，不在runner里加模型名分支。

## 时间估算的边界

若某固定工作量原先840秒，其中不随搜索额度缩放的部分为F，则理想四分之一额度是：

`T_quarter = F + (840 - F)/4 = 210 + 0.75F`

仅举例：F=60–180秒对应255–345秒（4分15秒–5分45秒），不是测量或承诺。低预算改变轨迹/平均链长、并行填充和固定开销，实际可偏离。新的训练工作量是1024×768行，不能把旧480完整自然游戏的14–15分钟直接换算为新一轮时间；新大编码器训练也可能成为开销。本阶段无任何新速度结果。

## 参考与不确定性

- [PPO原论文](https://arxiv.org/abs/1707.06347)：采样与基于旧策略的surrogate更新框架；本稿的旁路监督是新增联合目标，不声称论文已验证本游戏方案。
- [Expert Iteration原论文](https://arxiv.org/abs/1705.08439)：搜索提供改进计划、网络泛化并反过来引导搜索的方向；本稿的具体网络、预算、锚点及标签参数是待测设计。
- 主要未决项：压缩摘要的能力损失、V_A对搜索产生的新资源组合的泛化、低预算标签噪声、共享E梯度干扰、纯policy采样是否覆盖足够好的组合，以及CPU小网/批量GPU的实际交叉点。先按此单一方案验收，不预先引入大批无测试模式。
